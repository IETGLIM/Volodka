## Исправлено в этой сессии (commit `7b83a04`)

### P0 — критические
- **P0-1: ESLint полностью сломан.** Root cause: `@typescript/typescript6` имеет
  circular require (`lib/typescript.js` → `require("@typescript/old")` → снова
  `@typescript/typescript6` → пустой `{}`), из-за чего `@typescript-eslint` v8.64
  падал с `TypeError: Cannot read properties of undefined (reading 'Cjs')`.
  **Фикс:** убран dual-TS setup (TS6 alias + TS7 native Go), установлен стабильный
  `typescript@5.9.2`. Скрипты `tsc7.mjs` → `tsc --noEmit`. Typecheck остался 0 ошибок.
  **Линт-гейт снова жив** — это главный разблокатор.
- **P0-2: `verify-deploy-assets.ts` всегда падал** с `viteSingleFile` (assertion
  `indexHtml.includes('/assets/')` несовместим с инлайном всего в один HTML).
  Fixed: singlefile-aware проверка.

  `fx:screen_flash`, `photo:dpr_request`, `photo:lighting_boost`, `photo:motion_blur`)

## FreeRouter API — рекомендация (use-case)

[FreeRouter](https://freerouter.eu.cc/) — бесплатный OpenAI-совместимый роутер для
AI-моделей. Предоставленный ключ: `fr-7ENQDdDCXYthX7kBLqwJSzrpxeOfINEi` (пользователь
заменит позже).

**ВАЖНО: ключ НЕ должен попадать в клиентский бандл.** Volodka — статическое SPA на
Vercel, без бэкенда. Если ключ в клиенте — любой извлечёт и злоупотребит.

**Рекомендуемая архитектура (Vercel Serverless Function):**
1. Создать `api/matrix-quote.ts` — serverless function (Vercel Hobby поддерживает).
2. Ключ `FREEROUTER_KEY` — env var в Vercel dashboard (НЕ в репо).
3. `vercel.json` rewrite нужно ограничить, чтобы `/api/*` шли в функции, а не в SPA:
   `"rewrites": [{ "source": "/((?!api).*)", "destination": "/index.html" }]`
4. Клиент вызывает `fetch('/api/matrix-quote?scene=matrix_layer&karma=…')` — ключ скрыт.

**Use-case:** динамическая генерация Matrix-цитат для сцен «Matrix layer» (акты 4–5).
Сейчас `matrixQuotes.ts` имеет 77+ статичных цитат. LLM мог бы добавлять свежие
Matrix-style философские цитаты, реагирующие на текущую карму/выборы игрока. Это
**добавляет** контент, не трогая священные стихи (`poems.ts`) или основной сюжет.

**Альтернативный use-case:** динамические ambient barks для NPC (реагируют на
karma/выборы) — но рискованнее (может ломать narrative coherence).

**Статус:** дизайн предложен, реализация отложена на следующий заход (требует
создания serverless function + env var + проверки rate limits FreeRouter на free tier).
