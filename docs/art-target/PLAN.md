# Арт-таргет «street_night» — путь к AAA-кадру

> **Назначение:** этот документ — художественный ориентир и план доработок
> визуала Volodka. Итоговая цель: игровой кадр Three.js/R3F, неотличимый по
> настроению от `docs/art-target/street_night_target_2560.png`.
> Создано по просьбе автора 2026-11-18. VLM-арт-директор: вердикт «ДА —
> брать как главный арт-таргет» (свет 9/10, материалы 8/10, цельность 8/10).

---

## 1. Что на эталонном кадре (разбор на слои)

| Слой | Что видно | Как сделано (гипотеза реализации) |
|------|-----------|-----------------------------------|
| **Небо/купол** | Холодный сине-серый пасмурный сумеречный купол, лёгкий градиент к горизонту | HDRI `moonlit_golf` (уже есть) + при дождле пониженная экспозиция неба, тёмный тонемап |
| **Архитектура** | Панельки 5–9 эт. (хрущёвка/брежнёвка): потёки, шелушение краски, ржавые балконы, редкие тёплые окна, мигающая лампа подъезда | Существующие интерьерные шеллы + план: фасадные панельные дома с грязевыми декал-масками |
| **Двор-земля** | Сплошная вода: зеркальные лужи отражают дома, окна, фонарь и небо; тротуарные кромки рвут воду | `WetStreetGround` (есть) → усиление: SSR-зеркальность + puddle-маски (см. §3.1) |
| **Свет** | ОДИН натриевый фонарь конусом сквозь дождь + тёплые окна практиков + холодный купол | Motivated practicals: фонарь SpotLight с god-rays (есть GodRays), окна — emissive |
| **Объекты-якоря** | Ржавые качели-«лодочка», карусель, «Жигули» у бордюра, ларёк, доска объявлений, провисшие провода, мокрые листья | Quaternius/Kenney база + план: советские пропсы-якоря (см. §3.3) |
| **Атмосфера** | Дождь в конусе света, тонкий приземный туман, дымка глубины, зерно | `RainEffect` (есть) + `AtmosphericEffects` (есть) + filmic grain в пост-стаке |
| **Камера** | Уровень глаз, 3-е лицо, лёгкий DoF на передней луже | FollowCamera + DepthOfField из ExplorationPostFX (есть) |

**Ключевая формула кадра:** тёплый янтарь фонаря и окон против холодного
сине-серого купола. Один источник объёмного света. Ноль неона. Матовая
влажность вместо глянца.

## 2. Дельта-гэп: что уже есть в проекте vs эталон

| Компонент эталона | Состояние в проекте (v4.58) | Гэп |
|---|---|---|
| Мокрый планарный рефлектор | `WetStreetGround` для `street_night` + Ultra-SSR режим | Зеркальность луж ограничена размером рефлектора; нет puddle-масок вариативности |
| Дождь | `RainEffect` + детерминированный погодный директор | Брызги/кольца от капель в лужах не визуализированы |
| Свет фонаря конусом | GodRays-пресеты + N8AO + ACES | Мигающая лампа подъезда нет; конус недостаточно «сгущён» туманом |
| Постсоветские панельки | Интерьерные шеллы, citykit | Нет фасадов панельных домов с потёками/балконами как hero-ассетов |
| Качели/карусель/Жигули | Kenney/Quaternius пропсы общего плана | Нет узнаваемых советских якорей (Лодочка, Жигули, ларёк) |
| Приземный туман | AtmosphericEffects fog | Нет локальных приземных дымок под фонарём/решётками |
| Зерно/тонемап | Filmic + grain (v4.55 отсёк в TSX) | Мягче виньетка к краям, экспозиция сцены по LUT |

## 3. План итераций (порядок = «сначала свет и вода, потом пропсы»)

Каждая итерация — отдельная сессия HOURLY-цикла: маленький шаг, скриншот
до/после (`scripts/ui-review-capture.mjs`), сравнение с эталоном глазами
(VLM-запрос), коммит. Никаких стихов не касается (только `src/engine`,
`src/components/3d`, `public/`).

### Итерация A — Вода и отражения (самый большой визуальный выигрыш)
- **A1. Puddle-маски на мокрой земле**: шумовая маска (fbm) управляет
  roughness/металностью `WetStreetGround` — пятна зеркала между пятнами
  «мокрого асфальта». Параметр `puddleCoverage` из погодного директора.
- **A2. Ripple-нормали**: procedural ripple-текстура (два слоя,
  разная скорость) в normalMap луж во время дождя — «живая вода».
- **A3. Кольца-брызги**: 2–3 инстансированных спрайт-кольца на лужах
  под фонарём (только high-tier), затухающие анимацией.
- **A4. Прибой бордюров**: тонкий emissive-блик по кромке тротуара,
  где вода встречает бетон (термическая разница тёплых окон).

### Итерация B — Свет и атмосфера
- **B1. Мигающая лампа подъезда**: один RectArea/PointLight с
  sin-фликером (0.2 Гц, случайные пропуски) на фасаде — оживляет фон.
- **B2. Сгущённый конус фонаря**: SpotLight + локальный volumetric
  конус (cheap: аддитивный меш-конус с шумовой маской по высоте).
- **B3. Приземный туман**: 1–2 больших плоскости с градиентной
  альфой у земли, медленный дрейф; плотность из погодного директора.
- **B4. Виньетка/LUT-проход**: мягкая тёплая виньетка к краям кадра,
  лёгкий teal-shift теней (LUT 16×16, single texture fetch).

### Итерация C — Архитектура и пропсы (постсоветские якоря)
- **C1. Hero-фасад панельки**: один дом 5–9 эт. с декаль-потёками,
  ржавыми балконами, редкими emissive-окнами. Kenney citykit как база +
  маски грязи (уже есть генератор конвертов `generate-volodka-apartment-envelope`).
- **C2. Качели-«лодочка»**: пропс из бокса+цилиндров, ржавый материал
  (`metal_plate` PBR + ржавый tint), лёгкое покачивание на ветру.
- **C3. Жигули-силуэт»: low-detal box-модель с корректным мокрым
  лаком (clearcoat), номерной знак без текста, блики на капоте.
- **C4. Ларёк + доска объявлений**: одностворчатый киоск с тёплым
  окном-витриной; на доске — 3–4 «бумажки» (плоскости, БЕЗ читаемого
  текста — только пятна, как заметил VLM).

### Итерация D — Живость двора (микрожизнь)
- **D1. Капли с карнизов**: партиклы-капельники с краёв козырьков.
- **D2. Окна-события**: 2–3 окна тухнут/зажигаются по таймеру погоды.
- **D3. Пар из решётки**: медленный подъёмный спрайт-шум у люка.

### Итерация E — Склейка и замер
- **E1. Скриншот-контракт**: e2e-спека «street_night кадр» с фиксированной
  камерой, сохранение в `docs/evidence/` для сравнения с эталоном.
- **E2. FPS-бюджет каждой итерации**: замер до/после (measure-frame-profiler),
  high-tier не должен терять >5 FPS от текущих 60.
- **E3. Сторонний прогон VLM-судьи**: тот же промпт, что оценивал концепт,
  цель — 8+/10 по всем критериям на реальном кадре.

## 4. Правила работы с арт-таргетом

1. **Не превращать в погоню за фотореализмом ассетов** — эталон задаёт
   свет, влажность, палитру и настроение. Mesh-база остаётся CC0/процедурной.
2. **Каждая итерация обратима** (фиче-гейт по качеству, как весь пост-FX).
3. **Никакого неона** — только мотивированные практические источники.
4. **Сравнение — по скриншоту с той же камеры**, не по памяти.
5. Эталон и mood-версии лежат в `docs/art-target/` (коммиты: PNG не
   редактировать, только заменять целиком новыми итерациями).
