## 📖 О проекте

**ВОЛОДЬКА** — это 3D RPG с открытым миром в стиле киберпанк. История о программисте, который находит стихи, спрятанные в серверном коде, и discovers, что слова могут менять реальность.

Стихи в игре — авторства **Владимира Лебедева**. Они являются неотъемлемой частью нарратива и не подлежат изменению.

## 🎮 Особенности

- **15 3D-локаций** — от комнаты Володьки до заброшенного завода и края крыши
- **7 актов сюжета** с множественными концовками
- **55 квестов** — основная линия, побочные и эпилог (Tolpa)
- **Боевая система** — 11 типов врагов, комбо-атаки, баффы/дебаффы
- **12 NPC** с диалогами, расписаниями и отношениями
- **46 стихов** и **54 записи лора** — стихи дают особые способности в бою
- **Крафт и торговля** — создавай предметы, торгуй с NPC
- **Дерево навыков и перков** — прогрессия через акты (полный проход — многосессионный)
- **Динамическая погода** — дождь, снег, туман, шторм, день/ночь
- **Пост-обработка** — Bloom, виньетка, цветокоррекция, хроматическая аберрация
- **Адаптивная камера** — авто-следование, зум колесом, подстройка под масштаб локации
- **Физика на Rapier** — коллизии, инерция, прыжки

## 🛠️ Технологии

| Стек | |
|---|---|
| **Фреймворк** | React 19 + Vite 6 |
| **3D-движок** | Three.js 0.172 + React Three Fiber 9 |
| **Физика** | Rapier 2.2 (Kinematic Character Controller) |
| **Пост-обработка** | @react-three/postprocessing 3.0 |
| **Стейт** | Zustand 5 |
| **UI** | Tailwind CSS 4 + shadcn/ui + Radix UI |
| **Анимации** | Framer Motion 12 |
| **Деплой** | Vercel (SPA) |

## 🚀 Быстрый старт

```bash
npm install

npm run build    # Production-сборка в dist/
```

## 📦 Vercel Deploy

Проект готов к деплою на Vercel. `vercel.json` уже настроен:

1. Залей репозиторий на GitHub
2. Подключи Vercel к репозиторию
3. Vercel автоматически определит Vite и соберёт проект

## 📝 Версия и changelog

Текущая версия пакета: **3.0.1** (`package.json`). Ниже — заметки по ветке 3.x (исторический changelog; не обещает «AAA» / фиксированный час геймплея).

### Исправления (3.x)
- 🎥 **Камера адаптируется к масштабу локации** — 2.5м в комнатах, 6.5м на улицах
- 🧱 **Улучшенная коллизия** — skin width увеличен с 2см до 8см, персонаж не проходит сквозь мебель
- 🌧️ **MatrixRain больше не блокирует управление** в indoor-сценах (комната, коридор)

### Контент и инфраструктура
- Расширены лор, перки, крафт и предметы (см. `src/data/`)
- Кэширование статических ассетов в Vercel (immutable для JS/CSS/3D-моделей)
- Security-заголовки + CSP Report-Only / Permissions-Policy (`vercel.json`)
