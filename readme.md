## 📖 О проекте

**ВОЛОДЬКА** — это 3D RPG с открытым миром в стиле киберпанк. История о программисте, который находит стихи, спрятанные в серверном коде, и discovers, что слова могут менять реальность.

Стихи в игре — авторства **Владимира Лебедева**. Они являются неотъемлемой частью нарратива и не подлежат изменению.

## 🎮 Особенности

- **14 уникальных 3D-локаций** — от комнаты Володьки до заброшенного завода и края крыши
- **7 актов сюжета** с множественными концовками
- **40+ квестов** — основная линия, побочные, скрытые и ежедневные
- **Боевая система** — 9 типов врагов с уникальными способностями, комбо-атаки, система баффов/дебаффов
- **10 NPC** с полными диалоговыми деревьями, расписаниями и отношениями
- **Поэтическая магия** — собранные стихи дают особые способности в бою
- **Крафт и торговля** — создавай предметы, торгуй с NPC
- **Дерево навыков и перков** — прокачка на 80+ часов геймплея
- **Динамическая погода** — дождь, снег, туман, шторм, день/ночь
- **AAA пост-обработка** — Bloom, виньетка, цветокоррекция, хроматическая аберрация
- **Адаптивная камера** — авто-следование, зум колесом, подстройка под масштаб локации
- **Физика на Rapier** — коллизии, инерция, прыжки

## 🛠️ Технологии

| Стек | |
|---|---|
| **Фреймворк** | React 19 + Vite 6 |
| **3D-движок** | Three.js 0.172 + React Three Fiber 9 |
| **Физика** | Rapier 2.2 (Kinematic Character Controller) |
| **Пост-обработка** | @react-three/postprocessing 3.0 |
| **Стейт** | Zustand 5 |
| **UI** | Tailwind CSS 4 + shadcn/ui + Radix UI |
| **Анимации** | Framer Motion 12 |
| **Деплой** | Vercel (SPA) |
