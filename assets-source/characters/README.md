# Character Art Handoff — Володька (Hero)

Deliverable for Phase A: custom player mesh replacing CC0 CesiumMan placeholder.

---

## File naming

| File | Purpose |
|------|---------|
| `volodka.glb` | Source authoring mesh (place in this folder) |
| `public/models/characters/volodka/volodka_lod0.draco.glb` | Processed LOD0 (runtime) |
| `public/models/characters/volodka/volodka_lod1.draco.glb` | LOD1 (~50% tris) |
| `public/models/characters/volodka/volodka_lod2.draco.glb` | LOD2 (~20% tris) |

Registry entry: `src/config/assetManifest.ts` → `player_volodka`.

---

## Mesh requirements

| Spec | Requirement |
|------|-------------|
| **LOD0 triangle budget** | ≤ **12,000** tris |
| **LOD1 / LOD2** | Generated by pipeline (50% / 20% simplify) |
| **Scale** | ~1.75 m height; feet on ground plane (Y=0) |
| **Pivot** | Origin at floor between feet |
| **Skeleton** | Humanoid, **Mixamo-compatible** bone names |
| **Materials** | PBR (baseColor, normal, ORM); max 2K textures per slot |
| **Textures** | Power-of-two; pipeline emits **KTX2 Basis** atlases |

---

## Rig & animation

1. Rig in Blender or export from VRoid → cleanup → Mixamo retarget.
2. Minimum clips (Mixamo): **Idle**, **Walking**, **Running**, **Jumping**.
3. Clip names in GLB: `idle`, `walk`, `run`, `jump` (lowercase, engine retarget map).
4. Root motion: **off** for locomotion (engine drives position via Rapier KCC).

Optional Phase B: attack, hit react, dodge — separate GLB or additional actions in same file.

---

## Processing workflow

```bash
# 1. Place source file
cp volodka.glb assets-source/characters/volodka.glb

# 2. Run AAA pipeline (Draco, Meshopt, LODs, KTX2)
npm run assets:process
# or single file:
npm run assets:process -- --input assets-source/characters/volodka.glb

# 3. Validate manifest paths + triangle budgets
npm run assets:validate
```

Pipeline script: `scripts/process-gltf-assets.mjs`  
KTX2 transcoder: `public/basis/` (do not delete)  
Draco decoder: `public/draco/gltf/`
